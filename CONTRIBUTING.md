# Contribuer

Arklandia Engine est un fork de Pumpkin dont le code est publié sous GPL v3, mais **les contributions externes ne sont pas acceptées** : les pull requests sont réservées aux collaborateurs du dépôt.

## Ce que vous pouvez faire

- **Ouvrir une Issue** pour signaler un bug (modèle « Rapport de bug » : version, client, plugins, journal, étapes pour reproduire).
- **Discuter d'une idée ou d'une amélioration** dans une Issue. Elle sera examinée, mais rien n'est garanti.
- **Forker le dépôt** pour votre propre usage, dans le respect de la licence GPL v3 : conservez les mentions d'attribution (`NOTICE.md`) et publiez vos modifications sous GPL v3 si vous distribuez un binaire.

## Ce qui n'est pas accepté

- Les pull requests de personnes qui ne sont pas collaborateurs (GitHub les bloque).
- Les rapports de faille de sécurité en Issue publique : voir `SECURITY.md`.

## Pour les collaborateurs

- Branche `main` protégée : passer par une pull request, **fusion par rebase uniquement**, historique linéaire. La branche est supprimée après la fusion.
- Messages de commit en français, clairs, un commit par changement logique (ils arrivent tels quels sur `main`).
