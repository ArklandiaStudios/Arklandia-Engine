# Politique de sécurité

## Signaler une faille

**N'ouvrez jamais d'Issue publique pour une faille de sécurité.** Utilisez le signalement privé de GitHub :
https://github.com/ArklandiaStudios/Arklandia-Engine/security/advisories/new

Indiquez la version d'Arklandia Engine, les étapes pour reproduire et l'impact estimé. Un accusé de réception est envoyé dès que possible ; aucune échéance de correction n'est garantie.

## Versions concernées

Seule la dernière pré-version publiée est suivie.
